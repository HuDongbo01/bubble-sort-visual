# 冒泡排序可视化模拟器项目需求与设计文档

项目组：冒泡算法可视化小组



## 一、项目背景与目标

在《计算机基础》与数据结构课程学习中，冒泡排序是入门经典排序算法，但双层循环、比较交换过程较为抽象，初学者难以直观理解。本项目旨在开发一款轻量级桌面演示程序，将冒泡排序的比较、交换、冒泡过程动态可视化展示，帮助学习者直观理解冒泡排序的执行流程。



本项目为小组协作开发项目，基于 Python + Tkinter 实现，采用 Git 进行版本控制，多人分工完成需求设计、界面开发、算法实现、测试优化、汇报答辩等工作。



## 二、核心功能需求

本项目围绕冒泡排序算法可视化演示，需实现以下核心功能：

1. 随机数据生成：程序支持一键生成一组随机整数数组，用于排序演示；

2. 排序动画可视化：按照冒泡排序双层循环逻辑逐次执行，动态刷新柱状图；

3. 元素高亮提示：正在进行比较的两个柱形高亮标记，直观区分比较对象；

4. 执行控制台：

   - 支持一键启动排序动画；

   - 支持重置功能，重新生成数组，重复演示；

5. 结果展示：排序完成后展示有序数组，结束动画。



## 三、界面设计参考

本系统采用 Python 的 tkinter 库进行构建，窗口布局简洁，上方为功能按钮，下方为绘图画布，画布展示柱状图与对应数值。

- 窗口尺寸：800 × 400

- 背景：纯白色画布

- 展示形式：矩形柱形图 + 柱顶数字标注

- 配色方案：默认柱形蓝色，待比较柱形红色高亮

- 功能按钮：【开始排序】【重置】

## 五、核心算法设计

### 5.1 冒泡排序原理

冒泡排序重复遍历数组，依次比较相邻两个元素，如果逆序则交换；每一轮遍历都会将当前未排序部分的最大值“冒泡”到末尾。

- 外层循环：控制排序轮次

- 内层循环：相邻元素比较与交换

- 时间复杂度：最坏 O(n²)，最好 O(n)

- 空间复杂度：O(1)



### 5.2 可视化适配逻辑

每一次相邻元素比较 → 刷新画布，高亮当前两个柱形；

每一次元素交换 → 刷新画布，更新柱形高度；

延时控制动画速度，保证人眼可以清晰观察每一步算法执行。
