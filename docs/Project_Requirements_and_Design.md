# 冒泡排序可视化系统 —— 需求分析与系统设计文档

## 1. 项目概述
本项目基于 Python + Tkinter 开发 **冒泡排序算法动态可视化模拟器**。项目旨在通过图形动画方式直观展示冒泡排序每一轮比较、交换、遍历过程，解决传统算法学习抽象、难以理解的问题。系统支持随机数据生成、动态排序动画、实时高亮比较元素、重置重跑功能，适合数据结构与算法课程教学演示与课程大作业提交。

本项目为小组协作开发项目，采用 Git 进行版本控制，多人分工完成需求设计、界面开发、算法实现、文档撰写、测试优化等工作。

## 2. 功能需求
### 2.1 基础功能需求
1. **随机数据生成功能**
程序启动自动生成一组随机整数数据，数据区间合理，保证可视化柱状图高度区分明显。
2. **冒泡排序动态可视化**
按照标准冒泡排序流程逐次比较相邻两个元素，动画展示每一次比较、交换动作。
3. **元素高亮提示**
正在比较的两个柱形高亮变红，其余保持蓝色，让算法步骤清晰可辨。
4. **排序完成展示**
排序结束后所有柱形恢复默认颜色，展示有序结果。
5. **重置功能**
一键重新生成随机数组，可多次演示不同数据排序过程。
6. **开始排序功能**
点击按钮启动动画，避免程序自动运行导致观看不及时。

### 2.2 非功能需求
- 易用性：界面简洁、操作简单，无需配置直接运行。
- 稳定性：排序流程无卡顿、无报错、无闪退。
- 可维护性：代码分层清晰、注释齐全、目录规范、适合小组迭代。
- 可扩展性：可后续扩展排序速度调节、步数统计、排序次数展示。

## 3. 运行环境需求
- 操作系统：Windows10 / Windows11
- 编程语言：Python 3.8 及以上
- 依赖库：Tkinter（Python自带，无需额外安装）

## 4. 系统总体设计
### 4.1 整体架构
本系统采用**轻量图形界面事件驱动架构**，分为三层：
1. 数据层：随机数组生成、数据交换、排序逻辑
2. 视图层：画布绘制柱状图、颜色高亮、文字渲染
3. 交互层：按钮点击事件、动画刷新、延时控制

### 4.2 模块划分
1. **数据生成模块**：负责初始化随机整数数组，提供重置刷新功能。
2. **绘图渲染模块**：根据当前数组状态实时绘制柱形图，支持动态高亮。
3. **冒泡排序算法模块**：实现标准双层循环冒泡排序逻辑，每一步暂停刷新界面实现动画效果。
4. **界面交互模块**：包含窗口创建、按钮绑定、界面布局管理。

## 5. 核心算法设计
### 5.1 冒泡排序原理
冒泡排序重复遍历数组，**依次比较相邻两个元素**，若顺序错误则交换，每一轮遍历将当前最大元素“冒泡”至末尾。
- 外层循环：控制排序轮数
- 内层循环：每一轮相邻元素比较交换
- 时间复杂度：最坏 O(n²)、最好 O(n)
- 空间复杂度：O(1)

### 5.2 可视化适配逻辑
每一次**相邻元素比较** → 刷新画布并高亮两柱
每一次**元素交换** → 刷新画布展示交换结果
延时函数控制动画速度，保证人类可清晰观察每一步算法执行。

## 6. 界面设计
- 窗口大小：800×400
- 背景：纯白色干净画布
- 展示形式：矩形柱形图 + 顶部数值显示
- 颜色设计：
  - 默认柱形：蓝色
  - 正在比较柱形：红色高亮
- 功能按钮：【开始排序】【重置】
